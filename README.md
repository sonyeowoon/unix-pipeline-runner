# Unix Pipeline Runner

두 외부 명령을 파이프로 연결하고 파일 입력과 출력을 지정하는 C 시스템 프로그래밍 학습 프로젝트입니다. 셸 파이프라인의 프로세스 생성과 파일 디스크립터 연결 과정을 직접 다룹니다.

## 주요 구현

- `fork`로 두 자식 프로세스 생성
- `pipe`를 통한 명령 사이 데이터 전달
- `dup2`를 사용한 표준 입력·출력 재지정
- 환경변수의 실행 경로 탐색과 `execve` 호출
- 자식 프로세스 대기 및 오류 처리

## 기술

C, POSIX 프로세스, 파이프, 파일 디스크립터, 입출력 리디렉션, Make

## 빌드와 실행

Unix 계열 C 개발 환경과 Make가 필요합니다.

```sh
make
./pipex input.txt "grep hello" "wc -l" output.txt
```

기존 실행 파일 이름 `pipex`를 유지합니다. 위 예시는 입력 파일에서 `hello`가 포함된 줄을 찾고 그 줄 수를 출력 파일에 저장하는 흐름입니다. 입력 파일은 미리 준비해야 하며, 출력 파일은 생성되거나 기존 내용이 덮어써집니다.

## 코드 안내

- `pipex.c`: 프로세스 생성, 파이프 연결, 명령 실행
- `pipex_util.c`: 실행 경로 탐색 등 보조 처리
- `pipex_error.c`: 오류 처리
- `libft/`: 문자열 등 기본 보조 함수

## 범위와 제약

두 명령을 연결하는 구현이며 범용 셸이 아닙니다. 명령 문자열을 공백 기준으로 분리하므로 셸의 따옴표·이스케이프·변수 확장 문법 전체를 지원하지 않습니다. 빌드와 경계 조건의 실행 검증은 별도입니다.
